## Risks and explicit deviations

- **Deviation from CONTEXT Discretion: motion vocabulary (carry-forward from Plan 05-01).** CONTEXT line 85 suggests `reveal-on-scroll`; RESEARCH Q6 proves it does not fire on in-viewport mounts. Plan 05-02 uses `hero-fade-up` (globals.css line 335) via inline `style={{ animation: ... }}` with per-row 120ms stagger. The `prefers-reduced-motion` rule at globals.css line 613 covers the `.hero-reveal-*` class selectors — Task 1 instructs the executor to verify whether that rule covers inline `animation` usage and, if not, to ADD a one-line additive rule for `[style*="hero-fade-up"]` inside the same media query. This is the only acceptable globals.css edit in this plan.
- **Carry-forward note: `attending` string union.** Plan 05-01's FormState commits `attending: "yes" | "no" | null`. Phase 4's submit endpoint expects `attending: boolean`. Phase 6 transforms in its submit handler. Plan 05-02 does NOT wire onChange on the radios, so the runtime never assigns `attending` here — but the rendered radios use `value="yes"` and `value="no"` to match the locked string union shape Phase 6 will read.
- **F-02 deliberate divergence from Phase 4 enum.** Phase 4's submit route uses a `["chicken","fish","vegetarian"]` placeholder enum (CONTEXT D-14 / MEAL-03). Phase 5 deliberately uses `Option A/B/C` so the placeholder-ness is visibly obvious at code review and impossible to ship to production accidentally. Phase 6 / MEAL-02 swaps both at the same moment.
- **Disabled button defense in depth.** The `Confirm Group RSVP` button has `type="button"`, `disabled`, `aria-disabled="true"`, no `onClick`, and is NOT inside a `<form>` element. Four independent defenses against accidental submission in Phase 5. Phase 6 will add the `<form onSubmit={...}>` wrapper and change to `type="submit"`.
- **Uncontrolled inputs in Phase 5.** Radios and inputs have no `checked`/`value`/`onChange` to avoid React's "controlled-without-onChange" console warnings. Phase 6 converts to controlled inputs against the existing FormState shape. The `select` uses `defaultValue=""` with a sentinel disabled `Select a meal…` option for the same reason.
- **No regression in Plan 05-01 lookup stage.** Task 1's action explicitly forbids touching the state machine, refs, handlers, focus effects, errorCopy, or the lookup-stage render.
